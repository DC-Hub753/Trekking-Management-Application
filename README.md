\# Trekking Management Application



A web-based Trekking Management Application developed using Flask, SQLite, SQLAlchemy, HTML, CSS, Bootstrap and Flask-Login.



\## Features



\- User registration and login

\- Admin dashboard and trek management

\- Trek staff management

\- Trek booking system

\- Booking history and trek status tracking

\- Role-based access control

\- Staff participant management

\- Profile management

\- Search and filtering of treks



\## Technologies Used



\- Python

\- Flask

\- Flask-SQLAlchemy

\- Flask-Login

\- SQLite

\- HTML

\- CSS

\- Bootstrap

\- JavaScript
